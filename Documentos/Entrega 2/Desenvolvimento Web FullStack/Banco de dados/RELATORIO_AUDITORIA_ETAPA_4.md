As concessões padrão afetam futuros objetos; os acessos auditados às oito tabelas, suas sequências e às colunas sensíveis já foram conferidos, com anon/authenticated sem os direitos consultados. Não há funções/views em public. Isso reduz o risco imediato nesse escopo, mas não comprova segurança integral do projeto. EXECUTE global continua ativo para futuras funções. A revisão anterior mostrou possíveis impactos em extensões e rotinas internas se houver revogação global indiscriminada.

Controles para o adiamento: não criar/expor novos objetos sem revisão de privilégios; revisar especialmente cada futura função/RPC e SECURITY DEFINER; restringir a aplicação aos schemas aprovados; manter secret key somente no backend; preservar autorização e filtros do TrocaTicket.
