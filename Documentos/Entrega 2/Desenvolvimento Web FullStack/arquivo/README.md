# Arquivo historico do TrocaTicket

Os relatórios intermediários desta pasta foram preservados fora do repositório,
com estrutura relativa e hashes SHA-256 verificados, para reduzir documentação
histórica na entrega acadêmica. Os originais arquivados não foram reescritos.

- `RESULTADO_READMISSAO_CANONICA_20261103.md`
- `RESULTADO_READMISSAO_POS_T1_REAL_20261103.md`
- `RESULTADO_RESTABELECIMENTO_POS_T1_20261103.md`

O responsável pelo projeto mantém o arquivo local separado dos backups:
`ArquivoDocumentalTrocaTicket/markdown-fecap-20261106-185025-51ed7126`.
O `manifesto.json` desse arquivo registra caminhos originais, destinos e hashes.
O diretório `documentos/` preserva os caminhos relativos à raiz do Git.
A versão anterior deste índice também foi preservada antes da atualização.

Os planos superados `Banco de dados/eventos_imagens.preparacao.md` e
`PI Backend/HOMOLOGACAO_IMAGENS_PREPARACAO.md` foram preservados no mesmo arquivo.
As referências atuais são [Etapa 2 de imagens](<../Banco de dados/eventos_imagens.etapa2.md>)
e [homologação local de imagens](<../PI Backend/HOMOLOGACAO_IMAGENS_LOCAL.md>).

Resultados finais, contratos, segurança, schemas, RPCs, scripts, manifestos e
evidências de integridade continuam nos caminhos anteriores. Nenhum arquivo SQL,
código, teste, credencial ou backup foi alterado por esta organização documental.

As pastas `PI Backend/preparacao-*` foram mantidas porque contem codigo copiado, caminhos relativos e manifestos. Outros relatorios citados nos inventarios historicos tambem foram mantidos. Essas preparacoes, node_modules e dist ficam ocultos somente no Explorer do VS Code pela configuracao `.vscode/settings.json`; Git e execucao nao foram configurados de outra forma.

Removidos: build regeneravel `PI React/dist/` e os dois logs stderr vazios `controlador-restabelecimento-20261101.stderr.log` e `recuperacao-smoke-selado-20261101.stderr.log` em `PI Backend/evidencias/`.

Todos os assets foram preservados: a validacao visual independente permanece indisponivel pela protecao do navegador. Nenhum banco, JWT, checkpoint ou backup foi alterado.
